# Community Science Museum – Semester Project

A responsive, mobile‑first website built as part of my Semester Project.
The project focuses on semantic HTML, modern CSS (flexbox & grid), accessibility‑minded structure, and clean component reuse across pages.

## Features
- Fully responsive layout (mobile → tablet → desktop)
- Semantic HTML structure for improved accessibility and SEO
- Modern CSS using flexbox and grid for layout
- Mobile‑first design approach
- Reusable components for cards, navigation, and visit‑info sections
- Consistent typography and color system

## Recent Improvements
As part of final polishing, I updated the “Plan your visit” section to improve both UX and code quality:

### Clear distinction between interactive and static cards
- Added two new classes:
- 'visit-item-link' for clickable cards on the homepage
- 'visit-item-static' for informational cards on the Visit Us page
- This prevents hover effects on non‑interactive cards and improves clarity for users.

### Direct linking to Visit Us sections
- Homepage cards now link directly to the correct section on 'visit-us.html'
(e.g., 'visit-us.html#hours', 'visit-us.html#parking', etc.)
- This improves navigation, especially on mobile.

### Layout refinement on Visit Us page
- Added max‑width and padding to the visit‑info grid so cards no longer stretch edge‑to‑edge.
- Ensures consistent spacing and visual balance across pages.
